# ИИ-агент для автоматизации создания актов выполненных работ

Этот ИИ-агент создан как Proof of Concept для автоматического создания актов выполненных работ и счетов. Проект использует LangChain и GigaChat для создания интеллектуального агента, который генерирует документы на основе пользовательских данных.

## Возможности

- Создание актов выполненных работ
- Создание счетов
- Извлечение реквизитов контрагента из загруженного документа
- Опционально: получение данных из электронных писем

## Технологии

- Python 3.10+
- LangChain - фреймворк для разработки приложений на основе LLM
- GigaChat - языковая модель для обработки текста
- Typst - инструмент для генерации PDF-документов

## Установка и настройка

### Предварительные требования

- Python 3.10 или выше
- [Typst](https://github.com/typst/typst) (для генерации PDF-документов)
- Токен доступа к API GigaChat
- Документ с реквизитами ("Карточка НТЦ Татнефть.docx")

#### Установка Typst

Typst должен быть установлен в системе и доступен через командную строку:

```bash
# Для macOS с использованием Homebrew
brew install typst

# Для Linux через cargo (Rust)
cargo install typst

# Для Windows можно скачать бинарный файл с GitHub
# https://github.com/typst/typst/releases
```

### Создание .env файла

```bash
cp .env-example .env
```

Отредактируйте .env файл, указав необходимые параметры:

- GIGACHAT_CREDENTIALS - токен для подключения к API GigaChat
- EMAIL_LOGIN, EMAIL_PASSWORD и т.д. - для работы с электронной почтой (опционально)

### Установка зависимостей

С пакетным менеджером `uv`:

```bash
uv venv
uv sync
```

или с помощью pip:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

После запуска агент будет задавать вопросы для получения необходимых данных и генерировать акты выполненных работ и/или счета в формате PDF.

## Использование

### Подготовка документов

1. Подготовьте файл с реквизитами заказчика в формате .docx (по умолчанию "Карточка НТЦ Татнефть.docx").
2. Убедитесь, что файл находится в корневой директории проекта.

### Взаимодействие с агентом

При запуске агент спросит, что вы хотите сгенерировать:

- Акт выполненных работ
- Счет
- Оба документа

Затем агент запросит информацию о выполненных работах:

- Название работы
- Стоимость работы

После ввода всех данных агент сгенерирует PDF-документы в корневой директории проекта.

## Структура проекта

- `main.py` - основной файл с агентом и логикой работы
- `mail.py` - функциональность для работы с электронной почтой
- `typst/` - шаблоны для генерации PDF-документов
  - `act.typ` - шаблон для акта выполненных работ
  - `invoice.typ` - шаблон для счета
  - `ru-numbers.typ` - утилиты для работы с числами в русском формате
